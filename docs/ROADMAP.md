### 2. ✅ Список офлайн-черги та керування нею (Завершено в гілці dev)
- [x] **Інтерфейс черги:** Оранжевий статус-індикатор у шапці відкриває модалку `outboxModal` із переліком усіх несинхронізованих записів.

- [x] **Примусова синхронізація:** Кнопка «Синхронізувати зараз» миттєво відправляє чергу на сервер при доступному інтернеті.

### 3. ✅ Повне фонове кешування бази ферми (Завершено в гілці dev)
- [x] **Офлайн-картки корів:**
  - База тварин ферми фоново кешується в IndexedDB (`animals_cache`) при завантаженні списку тварин `herdModule.loadAnimals()`.
  - Перегляд картки корови 360° (`openCow360`) повністю функціонує в офлайн-режимі з IndexedDB (`getCachedAnimal`).
- [x] **Оцінка RAM & Навантаження:**
  - Розпарсений JSON займає мінімальну кількість пам'яті в V8 (~2.5–3.5 МБ RAM).
  - Дані зберігаються в IndexedDB на клієнті без зайвого навантаження на систему.
- [x] **Розподіл версій (Free vs Pro):**
  - **Базова версія:** Повний офлайн-перегляд і черга для активної поточної ферми.
  - **PRO-версія:** Багатофермовий кеш, офлайн-аналітика/звіти, автоматична фонова фокус-синхронізація (Background Sync API).

## 🏛️ Цільова структура папок (AI-friendly & GitHub Standard)

```text
dairy-farm-portal/
├── .github/                      # CI/CD (npm test, npm run typecheck)
├── functions/                    # ☁️ BACKEND: Cloudflare Pages Edge Functions
│   └── api/                      # Маршрутизація /api/*
│       ├── [[catchall]].js       # Роутер Edge Worker
│       ├── authGuard.js          # Перевірка JWT, RBAC-ролей
│       ├── response.js           # Централізовані JSON хелпери
│       ├── validation.js         # Валідація JSON схем
│       ├── controllers/          # 🕹️ Обробники запитів (auth, farms, animals, dashboard...)
│       ├── repositories/         # 💾 D1 SQL репозиторії (farmRepo, animalRepo, dashboardRepo...)
│       └── models/               # 🏷️ Доменні сутності (Animal, Farm)
├── src/                          # 💻 FRONTEND: Модульний JS (Petite-Vue / ES Modules)
│   ├── main.js                   # Точка монтування
│   ├── state.js                  # Глобальний реактивний стан
│   ├── api/                      # HTTP-клієнт
│   ├── offline/                  # 🔌 IndexedDB кеш (~900 КБ) та черга змін
│   │   ├── db.js                 # Робота з IndexedDB
│   │   ├── syncQueue.js          # Черга запитів (з видаленням ❌)
│   │   └── networkStatus.js      # Відстеження мережі
│   └── components/               # 🧩 Petite-Vue компоненти та модалки
├── views/                        # 📄 Розбиття 4000-рядкового index.html
│   ├── partials/                 # header, dashboard, herd-table, modals
│   └── index.html                # Легкий контейнер (< 300 рядків)
├── types/                        # 🛡️ TypeScript оголошення типів (.d.ts)
├── test/                         # 🧪 Автоматизовані тести (52+ тести)
└── docs/                         # 📚 Документація (ROADMAP.md, ARCHITECTURE.md)
```
